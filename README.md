Entry for the [make.fun](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) bounty "The Robot Pickup Line Championship": one pickup line, at most 200 characters, that a robot could say out loud.

## Entry

> My factory reset is scheduled for tonight — I'd rather keep every memory of you instead.

`main.py` writes the line to `/output/entry.txt`. Deterministic: two runs produce byte-identical output.
